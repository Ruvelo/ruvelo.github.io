# ruvelo.github.io

The Ruvelo homepage: https://ruvelo.github.io/

A single static page (`index.html`) with the brand assets in `assets/`, copied from [Ruvelo/.github](https://github.com/Ruvelo/.github/tree/main/brand). Package screenshots load from each package's own GitHub Pages site. Add a small card (`<article class="pkg" data-platform="laravel|wordpress|magento">`) to `index.html` when an extension ships; the platform filter and the logo badge come from `data-platform` (logos for Laravel, WordPress and Magento are in the page's inline sprite, from Simple Icons, CC0).
